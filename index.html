rclone-oauth

What is the purpose of this application?

rclone-oauth is a lightweight helper application designed to facilitate secure OAuth 2.0 authentication for the rclone command-line tool.

When you configure a new cloud storage provider (such as Google Drive, Microsoft OneDrive, or Dropbox) in rclone, the provider requires a secure web page to return your authorization token. Because rclone typically runs in a terminal or on a headless server, it cannot natively display this web callback.

This application simply acts as a secure bridge. It receives the authorization code from your cloud provider and immediately redirects it back to your local rclone setup to complete the connection.

Security & Privacy

This page is hosted entirely via GitHub Pages as static content. No personal data, files, or authentication tokens are ever collected, processed, or stored on our servers. The authentication flow happens directly between your browser, the cloud provider, and your local machine.
